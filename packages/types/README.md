# @emptysock/types

> Deprecated. Development has stopped; kept as a reference.

Zod schemas and inferred types for EmptySock's on-disk formats: the scene document (`SceneDocument`) and the project manifest. Shared by the engine, toolchain and IDE so all three validate the same shape.

```bash
pnpm --filter @emptysock/types build
pnpm --filter @emptysock/types test
```
